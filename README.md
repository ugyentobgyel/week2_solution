# Week 2 Logic Exercises - B-PIS

Files:
- data.php - the exact 8 records from the exercise sheet
- helpers.php - reusable functions
- ex1.php ... ex7.php - one solution per exercise

Run with XAMPP:
1. Put this folder inside C:\xampp\htdocs\b-pis\week2\ (or another folder under htdocs).
2. Start Apache in XAMPP.
3. Open http://localhost/b-pis/week2/ex1.php
4. Change ex1.php to ex2.php, etc.

Expected important outputs:
- ex1: none | 0, 19, BaC, 4ro
- ex2: Busiest: Paro (2 pending)
- ex4: 3 overdue · 1 follow up · 1 on time
- ex6: 5
- ex7: two duplicate CIDs and two invalid CIDs
